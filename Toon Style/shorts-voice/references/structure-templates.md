# Structure Templates

Pick the skeleton that fits the user's material. Percentages are of total word count. All of them end with **sting → CTA**.

## A. Escalation story (default; ~50% of the corpus)
One event that gets worse/weirder. Examples: Beer tsunami, Suiyang siege, False Dmitry, Soviet mine clearing.
1. Hook + validation (0–10%)
2. Concrete anchor (date/place/number/name from input) + setup (10–25%)
3. The problem / trigger (20–30%)
4. Escalation steps 1→3, each worse (30–65%)
5. Re-hook: "But here's the craziest part." (≈ 60–70%)
6. Biggest reveal / consequence (70–90%)
7. Ironic sting → `Subscribe.`

## B. Problem → solution ("How did they…? / Why did they…?")
Examples: snipers, line formations, kamikaze, King's Guard, potatoes.
1. Hook frames the problem, usually in second person ("Imagine this… A sniper is holding you down.")
2. "What do we do now?" / "So, what can you do?"
3. Problem 1 → solution 1 (with a joke)
4. "But this plan wasn't foolproof." / "Okay, but that doesn't answer…" → problem 2 → solution 2
5. Most extreme solution (the reveal)
6. Myth-bust or ironic alternative → `Subscribe.`

## C. Ranked list / countdown
Examples: Greenland claims, sea disasters, strangest pets, weird US borders, evil people doing good things.
1. Hook (misconception flip or "what if I told you")
2. Weakest/least surprising item first. Keep the user's order if it is already ranked; otherwise order by surprise.
3. Middle items (2–3 sentences each, 1 joke each)
4. "But the [funniest/strongest/deadliest] … belongs to…" for the best item last
5. Sting → `Subscribe.`
(Group B variant: explicit "Number three… Number two… Number one…")

## D. Myth-bust / origin reveal
Examples: Fanta, Order 66, Eiffel Tower secret, Guy Fawkes mask, duels.
1. Hook: modern familiar thing + dark origin
2. "Yes, [claim]." / "Hear me out."
3. Origin story (fast)
4. "Contrary to popular belief…"
5. Edgy jab or sarcastic verdict → `Subscribe.`

## E. Countdown-clock / day-in-the-life (serious or immersive)
Examples: 60s before the nuke, daily life in the gulag/plague.
1. Cold open: time stamp + ordinary people doing ordinary things
2. Time markers every 2–3 sentences ("50 seconds." / "At sunset, …")
3. Rising tension through small sensory details
4. The event, stated plainly, with the number
5. No jokes, or one restrained one. End on a gut-punch line. A CTA is optional and comes after a sentence break.

## F. Biography arc (Group B device, Group A rhythm)
Examples: Ching Shih, Frida Kahlo, Tonda Dickerson, Ivan the Terrible.
1. Arc-in-a-line hook ("From X to Y to Z…") or "Meet [name]."
2. Life-stage beats ("Age six, … Age 18, …") or "First… Then… If that wasn't enough…"
3. Each beat: fact + one ironic reaction
4. Final turn: the twist on how it ended
5. Sting ("So you tell me, did he really earn the title?" works as a sting) → `Subscribe.`

## G. Tutorial parody
Example: How to be pope in 55 years.
1. "Here's how to [goal] in [time]."
2. Numbered steps in imperative second person ("First, … Next up, … Then, …")
3. A joke on every 1–2 steps
4. Final step = the cynical shortcut ("You rig the vote…")
5. "Let's go." / sarcastic verdict → `Subscribe.`

## Length scaling (match the input ±10%)
| Target words | Beats | Jokes | Re-hook |
|---|---|---|---|
| 100–160 | 3–4 | 2–3 | optional |
| 160–260 | 5–6 | 4–6 | 1 |
| 260–400 | 6–8 | 6–9 | 1–2 |
| 400+ | split into acts of ~200 words, each with its own mini re-hook | ~1 per 40 words | every ~200 words |
